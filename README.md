# 🌀 Kasane Teto — фан-сайт

Анимированный фан-сайт про Касане Тето (重音テト): кто она, профиль, история, песни и случайные факты.

## Как открыть
- Локально: просто открой `index.html` в браузере.
- Онлайн: **Settings → Pages → Branch: `main` / root → Save**. Через минуту сайт будет по адресу `https://<твой-ник>.github.io/test-AI/`.

## Файлы
- `index.html` — разметка
- `style.css` — стили и CSS-анимации
- `script.js` — фон с падающими багетами, печатающийся текст, счётчики, факты
